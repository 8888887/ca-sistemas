# Imágenes de Salud y Seguridad Ocupacional

La pantalla utiliza las cinco imágenes originales facilitadas por el usuario. Se guardan como PNG, sin generación, sustitución ni modificaciones, en `public/images/soluciones/salud-y-seguridad-ocupacional/`.

| Archivo | Sección |
| --- | --- |
| `plataforma-salud-seguridad.png` | Cabecera: vista del módulo de Seguridad y Salud Ocupacional. |
| `identificacion-de-riesgos.png` | Identificación de riesgos e implementación de protocolos. |
| `registro-de-incidentes.png` | Registro de incidentes y análisis de tendencias. |
| `capacitacion-seguridad.png` | Capacitación de colaboradores ante emergencias. |
| `integracion-planillas-asistencia.png` | Integración de salud y seguridad con planillas y asistencia. |

La imagen de diseño se conserva para revisión en `artifacts/safety-design-reference.png`, fuera de los recursos publicados. La captura del software conserva su texto original; las descripciones accesibles y el contenido HTML de la pantalla se traducen entre español e inglés.
