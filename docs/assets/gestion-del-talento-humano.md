# Imágenes de Gestión del Talento Humano

La pantalla utiliza las cuatro imágenes originales proporcionadas por el usuario, guardadas como PNG sin modificaciones en `public/images/soluciones/gestion-del-talento-humano/`.

| Archivo | Sección |
| --- | --- |
| `plataforma-talento.png` | Vista del módulo de Gestión de Talentos en la cabecera. |
| `seleccion-incorporacion.png` | Selección e incorporación de personal. |
| `evaluacion-desempeno.png` | Evaluación del desempeño. |
| `reportes-desarrollo.png` | Reportes y desarrollo del talento. |

La imagen del diseño se conserva para revisión en `artifacts/talent-design-reference.png`. La captura del software mantiene su texto original; los títulos, los beneficios, las preguntas, el formulario y las descripciones accesibles de las imágenes se traducen entre español e inglés.
