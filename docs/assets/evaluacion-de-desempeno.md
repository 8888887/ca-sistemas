# Recursos de Evaluación de Desempeño

La pantalla `/soluciones/evaluacion-de-desempeno` usa las dos fotografías PNG adjuntadas y los cinco SVG originales facilitados por el usuario. Los SVG se copiaron desde los archivos indicados en Descargas, verificando que las copias conservan sus hashes. No se modificaron las fotografías ni los iconos.

Los archivos están en `public/images/soluciones/servicios-adicionales/recursos-humanos/evaluacion-de-desempeno/`:

| Archivo | Uso |
| --- | --- |
| `evaluacion-digital.png` | Cabecera |
| `evaluacion-equipo.png` | Explicación del servicio |
| `icons/indicadores-claros.svg` | Indicadores claros y personalizables |
| `icons/seguimiento-continuo.svg` | Seguimiento continuo |
| `icons/reportes-analiticas.svg` | Reportes y analítica inteligente |
| `icons/clima-laboral.svg` | Mejora del clima laboral |
| `icons/normativas-locales.svg` | Normativas locales |

La referencia completa se conserva en `artifacts/performance-design-reference.png`. Los textos siguen el diseño proporcionado por el usuario.

La funcionalidad está en `features/soluciones/servicios-adicionales/recursos-humanos/evaluacion-de-desempeno/`, con HTML, CSS y TypeScript en `pages/evaluacion-de-desempeno/` y contenido en `data/`. Se registra en las rutas de Recursos Humanos y reutiliza el catálogo central, header, footer, animaciones, preguntas frecuentes y formulario de servicios.
