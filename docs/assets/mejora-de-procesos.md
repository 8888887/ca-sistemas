# Recursos de Levantamiento y mejora de procesos

La pantalla `/soluciones/mejora-de-procesos` utiliza las tres fotografías PNG y los cinco SVG originales facilitados por el usuario. Los SVG se copiaron desde los archivos indicados en Descargas, conservando su contenido exacto. No se modificaron las fotografías ni los iconos.

Los recursos están en `public/images/soluciones/servicios-adicionales/gestion-empresarial/mejora-de-procesos/`:

| Archivo | Uso |
| --- | --- |
| `revision-procesos.png` | Cabecera del servicio |
| `crecimiento-empresa.png` | Presentación del levantamiento de procesos |
| `operacion-control.png` | Explicación del control de la operación |
| `icons/operacion-real.svg` | Mejora continua |
| `icons/crecimiento.svg` | Crecimiento ordenado |
| `icons/eficiencia-productividad.svg` | Eficiencia y productividad |
| `icons/decisiones-gerenciales.svg` | Decisiones gerenciales |
| `icons/organizacion.svg` | Preparación para el cambio |

La referencia se conserva en `artifacts/process-design-reference.png`. El contenido y los títulos siguen el diseño confirmado por el usuario.

La funcionalidad está en `features/soluciones/servicios-adicionales/gestion-empresarial/mejora-de-procesos/`, con HTML, CSS y TypeScript en `pages/mejora-de-procesos/` y contenido en `data/`. Se registra en las rutas de Gestión Empresarial y reutiliza el catálogo central, header, footer, animaciones, preguntas frecuentes y formulario de servicios.
