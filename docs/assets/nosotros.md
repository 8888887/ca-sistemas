# Recursos de Nosotros

La pantalla `/nosotros` conserva las diez imágenes PNG originales adjuntadas por el usuario en `public/images/nosotros/`. La referencia completa está en `artifacts/nosotros-design-reference.png`.

| Archivo | Uso |
| --- | --- |
| `equipo-ca-sistemas.png` | Fotografía principal del equipo |
| `soporte-capacitacion.png` | Primera fotografía de la galería |
| `equipo-oficina.png` | Segunda fotografía de la galería |
| `asesoria-equipo.png` | Tercera fotografía de la galería |
| `innovacion.png` | Valor innovación |
| `responsabilidad.png` | Valor responsabilidad |
| `auditoria-laboral.png` | Servicio de auditoría laboral |
| `hr-analytics.png` | Servicio de HR Analytics |
| `ley-30709.png` | Servicio de implementación de la Ley 30709 |
| `payroll.png` | Servicio de procesamiento de planillas |

Los iconos restantes usan SVG del componente compartido `app-icon`. Los círculos decorativos se dibujan con CSS. No se generaron fotografías ni se modificaron los archivos adjuntos.

La historia, los textos y los valores se mantienen en `features/nosotros/data/nosotros.data.ts`. Los componentes de misión/visión, valores y servicios están en `features/nosotros/components/`, cada uno con HTML, CSS y TypeScript separados. Las traducciones están en `shared/i18n/en.ts`.
