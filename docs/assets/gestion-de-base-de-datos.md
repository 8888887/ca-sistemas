# Recursos de Administración y Gestión de Base de Datos

La pantalla `/soluciones/gestion-de-base-de-datos` utiliza las dos imágenes PNG y los cinco SVG originales facilitados por el usuario. Los SVG se copiaron desde los archivos indicados en Descargas, conservando su contenido exacto. No se modificaron las imágenes ni los iconos.

Los recursos están en `public/images/soluciones/servicios-adicionales/tecnologia-y-seguridad/gestion-de-base-de-datos/`:

| Archivo | Uso |
| --- | --- |
| `administracion-sql-server.png` | Cabecera del servicio |
| `sql-server.png` | Presentación de SQL Server |
| `icons/mantenimiento-preventivo.svg` | Administración y mantenimiento |
| `icons/seguridad-respaldo.svg` | Seguridad y respaldo |
| `icons/consultas-respaldo.svg` | Optimización de consultas |
| `icons/recuperacion-desastres.svg` | Disponibilidad y recuperación |
| `icons/soporte-tecnico.svg` | Soporte técnico |

La referencia se conserva en `artifacts/database-design-reference.png`. El contenido sigue el diseño proporcionado por el usuario.

La funcionalidad está en `features/soluciones/servicios-adicionales/tecnologia-y-seguridad/gestion-de-base-de-datos/`, con HTML, CSS y TypeScript en `pages/gestion-de-base-de-datos/` y contenido en `data/`. Se registra en las rutas de Tecnología y Seguridad y reutiliza el catálogo central, header, footer, animaciones, preguntas frecuentes y formulario de servicios.
