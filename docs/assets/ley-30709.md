# Recursos de Implementación de la Ley N.° 30709

La pantalla `/soluciones/ley-30709` usa las seis imágenes PNG originales adjuntadas por el usuario, sin modificaciones. Se guardan en `public/images/soluciones/servicios-adicionales/recursos-humanos/ley-30709/`.

| Archivo | Uso |
| --- | --- |
| `implementacion-ley.png` | Cabecera del servicio |
| `modelo-factores-puntos.png` | Modelo de factores y puntos |
| `valoracion-puestos.png` | Valoración y categorización de puestos |
| `bandas-salariales.png` | Diseño de bandas salariales |
| `politicas-internas.png` | Propuestas de políticas internas |
| `diagnostico-salarial.png` | Diagnóstico salarial |

La referencia completa está en `artifacts/law-design-reference.png`. El contenido corresponde al diseño proporcionado por el usuario. Las dos últimas respuestas de preguntas frecuentes se adaptaron a la valoración de puestos, diagnóstico y bandas salariales, pues la referencia conservaba respuestas de Auditoría Laboral.

La funcionalidad está en `features/soluciones/servicios-adicionales/recursos-humanos/ley-30709/`, con HTML, CSS y TypeScript en `pages/ley-30709/` y contenido en `data/`. Reutiliza el catálogo de servicios, header, footer, preguntas frecuentes, formulario y animaciones. La ruta se registra en `recursos-humanos.routes.ts`.
