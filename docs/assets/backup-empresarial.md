# Recursos de Backup Empresarial

La pantalla `/soluciones/backup-empresarial` utiliza las dos imágenes PNG y los cinco SVG originales facilitados por el usuario. Los SVG se copiaron desde los archivos indicados en Descargas, conservando su contenido exacto. No se modificaron las imágenes ni los iconos.

Los recursos están en `public/images/soluciones/servicios-adicionales/tecnologia-y-seguridad/backup-empresarial/`:

| Archivo | Uso |
| --- | --- |
| `backup-servidores.png` | Cabecera del servicio |
| `respaldo-informacion.png` | Presentación del backup profesional |
| `icons/copias-automaticas.svg` | Copias programadas |
| `icons/almacenamiento-seguro.svg` | Almacenamiento seguro |
| `icons/recuperacion-rapida.svg` | Recuperación de información |
| `icons/compatible-con-bases-datos.svg` | Motores de bases de datos |
| `icons/cumplimiento-normativo.svg` | Cumplimiento normativo |

La referencia se conserva en `artifacts/backup-design-reference.png`. La composición y el contenido siguen el diseño del usuario, corrigiendo el subtítulo de Pentesting para que corresponda al servicio de backup.

La funcionalidad está en `features/soluciones/servicios-adicionales/tecnologia-y-seguridad/backup-empresarial/`, con HTML, CSS y TypeScript en `pages/backup-empresarial/` y contenido en `data/`. Se registra en las rutas de Tecnología y Seguridad y reutiliza el catálogo central, header, footer, animaciones, preguntas frecuentes y formulario de servicios.
