# Blog

El contenido procede del archivo `Blog_CA_Sistemas.html` proporcionado por el usuario.

- Se conservan sus siete títulos, extractos, resúmenes y categorías, sin añadir fechas, autores ni publicaciones nuevas.
- Las siete imágenes WebP embebidas se extrajeron a `public/images/blog/` conservando los bytes originales. Su procedencia figura en `public/images/sources.json`.
- El HTML y sus scripts se adaptaron a componentes Angular; los estilos permanecen en sus propios archivos CSS y las medidas fijas usan píxeles.
- La página reutiliza la cabecera y el footer existentes. El enlace para reuniones conduce al formulario de contacto del sitio.
- Los textos originales se mantienen en español y sus traducciones de interfaz y contenido están en `src/app/shared/i18n/en.ts`.
